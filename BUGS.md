# EMOTICORE TD - Bug Tracker

Living bug list for the closed alpha. Add new entries at the top of each section. Mark fixed entries with `[FIXED <date> <commit>]`.

## How to file

- Title: short, action-oriented (e.g. "Pride upgrade lock state desyncs after sell").
- Steps: minimal repro, including run config, map, and wave when possible.
- Expected vs. actual.
- Run snapshot: paste the JSON from `COPY RUN SUMMARY` (Victory/Defeat panel or DevTools).
- Screenshot or short clip if visual.
